# Web Scraping Projects

Python scripts that extract data from websites and save it to clean Excel files.

## Projects

- **scrape.py**: scrapes book titles and prices from the first page of a bookstore site.
- **books_all.py**: scrapes all 50 pages (about 1000 books) with price, rating, availability, and link.
- **books_filtered.py**: same as above, but keeps only books under £20 with a 5-star rating.
- **quotes.py**: scrapes quotes, authors, and tags across all pages, following the "Next" button automatically.

## Tools

Python, requests, BeautifulSoup, openpyxl

## Output

Each script saves its results to an Excel (.xlsx) file, included in this repo as samples.
